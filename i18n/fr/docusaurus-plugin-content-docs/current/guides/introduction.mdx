# Introduction {#introduction}

IPAC est an operations system pour industrial packaging work. It consists de two
applications that share a single backend:

- **Mobile** — a React Native / Expo application utilisé par field
  opérateurs, avec separate interfaces pour administrative utilisateurs et packers.
- **website** — a TanStack Start web application utilisé par managers et
  administrators, which also serves restricted client-facing views.

Both applications talk vers le **même Supabase project**: authentification,
PostgreSQL, row level sécurité, Storage, et base de données fonctions. That single
partagé backend est le most important fact about this system, et le source de
most de its risque.

## How much you peut trust a page {#how-much-you-can-trust-a-page}

Every page carries a statut banner. It est le mechanism that keeps this site
honest as it grows.

| Banner | Meaning |
| --- | --- |
| **Vérifié** | Every claim a été vérifié against le listed sources on le stated date. |
| **Partiellement Vérifié** | Some claims ont été vérifié; others sont inherited depuis earlier material et ne independently confirmed. le page says which. |
| **Ouverte Question** | A genuine contradiction ou gap. It est recorded, ne resolved par guessing. |

Two rules follow depuis this, et they sont ne negotiable:

1. **Nothing est invented.** Non table, rôle, workflow, ou behaviour est described
   here unless it a été observed dans le dépôts, dans le base de données, ou dans
   existant documentation that est cited.
2. **Contradictions sont published, ne settled.** Where existant sources
   disagree, le disagreement est written down on le
   [Ouverte questions](/docs/reference/open-questions) page until someone verifies
   le answer against le live system.

Si you find a page that contradicts le code, le code est right et le page est
a bug. Fix it, et update its statut banner.
