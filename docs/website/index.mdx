# website

This section covers the `ipacapps/website` application. It is the web application
for IPAC operations and client-facing portal routes, backed by the shared Supabase
project.

## Current stack

The current `website/package.json` uses React 19, TanStack Start, TanStack Router,
TanStack Query, Vite 7, Supabase JS, Tailwind CSS 4, DaisyUI, Zod, Vitest, Biome,
and TypeScript.
