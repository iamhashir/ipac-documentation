# AI authorship policy

This repository treats documentation prose as human-owned content.

## Required behavior for AI assistants

- Do not write, rewrite, expand, polish, or fill in documentation prose on your own.
- Before adding or changing documentation wording, show the user what is wrong or missing and ask for explicit permission to draft replacement text.
- A request to audit, review, fact-check, clean up, or remove "AI slop" is not permission to invent replacement prose.
- When removing low-quality generated prose, prefer identifying or deleting the problematic text. Do not replace it with newly generated prose unless the user explicitly approves that writing.
- You may inspect repositories, compare claims with source code or the live system, identify contradictions, flag unsupported statements, and recommend what needs attention without asking first.
- Do not infer facts to make a page sound complete. If a claim cannot be verified, leave it unresolved and follow the repository's open-question process.

## Approval boundary

Explicit approval to write applies only to the scope the user approved. Do not treat approval for one paragraph, page, or task as blanket permission to generate documentation elsewhere.

When in doubt: stop before writing prose and ask.
